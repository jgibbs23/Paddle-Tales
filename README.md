# Paddle Tales 🏓

A retro-cyberpunk Pong game built with vanilla JavaScript, HTML5 Canvas, and Web Audio API.

## Features
- Dynamic particle physics engine with floor collision and persistence
- Adaptive dynamic background music & synth drone scaling
- Best-of-5 sets match mode with local score/PP saving
- Fully frame-rate independent physics (supports 60Hz - 300Hz+)

## How to Play
1. Download `paddletales.html` (or click raw/download).
2. Open the file in any modern web browser.
3. Use `W`/`S` or `Arrow Keys` to move, and `Space` to serve/start.
